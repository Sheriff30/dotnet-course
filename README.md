# 🎓 كورس .NET من الصفر للاحتراف

## طريقة الشغل
- كل مرحلة في فولدر لوحدها.
- كل درس: شرح ← أمثلة ← تمرين ← مراجعة.
- لما تخلّص مرحلة، قول لـ Claude "خلصت" وننتقل للي بعدها.

## 📊 متابعة التقدم
علّم على المرحلة اللي خلّصتها بتغيير `[ ]` لـ `[x]`.

- [x] **00 - التجهيز:** يعني إيه .NET، التسطيب، أول برنامج، Git
- [ ] **01 - أساسيات C#:** المتغيرات، الشروط، الـ Loops، الـ Methods، الـ Collections
- [ ] **02 - OOP:** Classes، Inheritance، Polymorphism، Interfaces، SOLID
- [ ] **03 - C# متقدم:** Exceptions، Generics، LINQ، Delegates، Async/Await، Files و JSON
- [ ] **04 - SQL:** SQL Server، Queries، JOINs، Keys، Indexes، Stored Procedures
- [ ] **05 - EF Core:** DbContext، Migrations، العلاقات، CRUD، الأداء
- [ ] **06 - Web API:** REST، Controllers، DI، DTOs، Validation، Middleware، Swagger
- [ ] **07 - Security:** Identity، JWT، Roles و Policies، CORS
- [ ] **08 - Architecture:** Clean Architecture، Repository، CQRS، Design Patterns
- [ ] **09 - الجودة:** Unit و Integration Testing، Logging، Caching، Background Jobs
- [ ] **10 - Deployment:** Docker، CI/CD، النشر على السيرفر
