⚠️ مفيش أي تغيير بيروح للـ Database غير لما تكتب db.SaveChanges(). قبلها، التغييرات بتبقى في الذاكرة بس.

1. Create: إضافة

var member = new Member { FullName = "Sherif Fouad" };

db.Members.Add(member);     // 1. mark it as "Added"
db.SaveChanges();           // 2. send INSERT to the database

Console.WriteLine(member.Id);   // the new Id from the database!

لاحظ: إنت مكتبتش Id، بس بعد SaveChanges() هتلاقيه اتملى لوحده بالرقم اللي SQL Server عمله.

أكتر من حاجة مرة واحدة:

db.Members.AddRange(
    new Member { FullName = "Mona Ali" },
    new Member { FullName = "Ahmed Hassan" }
);
db.SaveChanges();

3. Update: تعديل ⭐

هنا السحر. مفيش دالة Update. إنت بس بتجيب الـ Object، وتغيّر فيه، وتحفظ:

var book = db.Books.Find(1);    // 1. get it
book.Price = 999;               // 2. change it
db.SaveChanges();               // 3. save it

والـ SQL اللي هيطلع:

UPDATE [Books] SET [Price] = @p0 WHERE [Id] = @p1;

لاحظ: بيحدّث Price بس، مش كل الأعمدة.

عرف منين إن السعر اتغيّر؟ Change Tracking

لما بتجيب أي Object من الـ Database، EF Core بيحتفظ بـ نسخة منه. ولما تعمل SaveChanges()، بيقارن الـ Object بالنسخة، ويعرف إيه اللي اتغيّر بالظبط.

وكل Object ليه حالة (State):

الـ StateمعناهاSaveChanges() هيعمل
Addedاتضاف بـ Add()INSERT
Unchangedجبته ومغيّرتش حاجةولا حاجة
Modifiedغيّرت فيهUPDATE
Deletedاتعمله Remove()DELETE

تقدر تشوفها بنفسك:

Console.WriteLine(db.Entry(book).State);   // Unchanged → Modified

4. Delete: مسح

var member = db.Members.Find(10);

if (member == null)
{
    Console.WriteLine("Member not found");
}
else
{
    db.Members.Remove(member);
    db.SaveChanges();
}
⚠️ دايماً اتشيّك على null قبل ما تعدّل أو تمسح. لو العضو مش موجود و عملت Remove(null)، البرنامج هيقع. وده نفس اللي هيحصل في الـ API: لو مش موجود ← ترجّع 404 Not Found.

5. SaveChanges() = Transaction

كل التغييرات اللي قبل SaveChanges() واحدة بتتنفذ مع بعض، يا كلها يا مفيش:

db.Members.Add(newMember);
book.Price = 500;
db.Categories.Remove(oldCategory);

db.SaveChanges();   // INSERT + UPDATE + DELETE: all or nothing

لو أي واحدة فيهم فشلت، الكل بيترجع. زي BEGIN TRANSACTION اللي أخدناه في SQL.

💡 النسخة الـ Async

كل الدوال دي ليها نسخة Async: ToListAsync() و FindAsync() و SaveChangesAsync(). وهي اللي هنستخدمها في الـ API. دلوقتي كمّل بالعادية.
